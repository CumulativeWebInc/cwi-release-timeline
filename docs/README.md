# Release Timeline Automator

$0 countdown generator — give it a release date, get the full dated checklist + content specs for the release cycle:

- **T-6wk** — distributor freeze (master lock, ISRC/UPC, metadata, artwork, rights)
- **T-4wk** — editorial pitch (Spotify for Artists ≥7-day rule, curator shortlist, EPK, radio)
- **T-2wk** — tease (snippet window: 2–4 weeks out, 15–30s vertical hooks)
- **T-1wk** — push (1–3 posts/day cadence, premiere, UGC templates)
- **Release day** — 3–5 core assets + first-2-hours engagement shift
- **Post-release** — waterfall of 20–30 micro-assets over 4 weeks + analytics reviews

Every content task is wired to peak-hour windows from 2026 platform research (compiled 2026-09-18; source + confidence shown per task — tune against your own analytics). Business tasks (distributor, editorial, press) auto-shift off weekends onto the preceding Friday.

**Use it:** open `index.html` (this `/docs` folder is deployed on GitHub Pages) → pick a date → Generate → copy as text or download `.ics`.

Deterministic: same date → same timeline. No network, no data leaves the browser, zero dependencies.
